in the browser

  • Files. Open folder edits a folder on your disk (Chromium-based browsers). Saves go to disk, and changes made elsewhere show up within seconds; a tab with unsaved changes keeps them. If a file changed on disk since it was read, a save does not overwrite it: the tab stays unsaved and the next save does. Elsewhere, files are copied into this browser; Download writes one out.
  • Sessions. The browser's files and each folder keep their own tabs and unsaved text, in this browser's private storage. Clearing the site's data clears them.
  • No programs. Formatters (f4) and the filter (alt+x) need a process, which a page cannot start.
  • Keys. The browser keeps ctrl+t, ctrl+w and ctrl+pgup/pgdn; alt stands in for ctrl on those. Every other key is native.
  • One tab. A second tab offers to take the editor over, so two never overwrite each other.

settings

/mibi.ini, shared by every workspace; a mibi.ini in your folder wins.
