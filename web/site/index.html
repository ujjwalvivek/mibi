Web build: what is different

  • Files. In Chromium-based browsers, Open folder is a real folder: saves go to disk, and changes made elsewhere show up within a few seconds (a tab with unsaved changes keeps them). If a file changed on disk after the editor read it, a save does not overwrite it: the tab stays unsaved and the next save does. Other browsers import a copy that lives in this browser; Download writes the current file out.
  • No external commands. Formatters (F4) and the filter (Alt+X) run programs, which a page cannot.
  • Some keys belong to the browser. Ctrl+W, Ctrl+T, Ctrl+N and a few more never reach the page. The toolbar has every editor key that matters.
  • No kitty keyboard protocol. xterm.js does not implement it, so kitty_keys has no effect.
  • One tab at a time. A second tab offers to take the editor over, so two never overwrite each other's session.
  • Storage. The session, unsaved text and imported files are kept in this browser's private storage (OPFS). Clearing the site's data clears them.

Settings: /mibi.ini, or a mibi.ini in your folder. Licences: mibi (MIT), xterm.js and its fit addon (MIT), and the terminal font, a subset of Maple Mono NF (OFL-1.1).
