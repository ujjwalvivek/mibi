Web build: what is different

  • Files live in the browser or a real folder. In Chromium, Open folder is a real folder and Save writes back to it. Elsewhere, Open imports a snapshot into a virtual workspace; use Download to put the current file on disk.
  • No external commands. Formatters (F4) and the filter (Alt+X) need to spawn a process, which a browser cannot do.
  • No automatic live reload. In a real folder, use Refresh to pick up changes made outside the editor; a snapshot cannot see them at all.
  • Some browser shortcuts win. Ctrl+W, Ctrl+T, Ctrl+N, Ctrl+R, F5 and F12 are reserved by the browser; the editor cannot always prevent them. The toolbar duplicates every editor key that matters, including Find, Replace, splits, panes, tabs, Keys and Quit.
  • Kitty keyboard protocol is unavailable. xterm.js does not implement it, so kitty_keys has no effect here.
  • The terminal font is bundled. The page uses a WOFF2 subset of Maple Mono NF, so the file tree's Nerd Font icons work without installing anything. Glyphs outside the subset fall back to the browser's fonts.
  • Storage is small. Snapshot workspaces and sessions are kept in localStorage (about 5 MB); a real folder's files are on disk. Download important snapshot files.
